# Elfen Lied Fighting v1.0.0-rc1

First public Android release candidate of the old Elfen Lied fan-made PC fighting game.

## Features

- Standalone Android version — no Windows or emulator required
- Touch/multitouch controls
- Original characters, stages, music and story content
- English / Japanese / Russian
- Android 10+

This is an unofficial non-commercial port. Original game by **ねくぱっち**. Elfen Lied and the original assets belong to their respective rights holders.

## Known limitations

- RC build: feedback and bug reports are welcome
- Online play is not publicly available yet
- Exact frame-perfect equivalence with the old Windows runtime is not guaranteed
