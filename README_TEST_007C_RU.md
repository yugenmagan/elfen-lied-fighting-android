# Elfen Lied Fighting — TEST 007c

Минорное обновление управления поверх 007b. Это не TEST 008.

## Установка

1. Скачайте `elfen-007c.apk`.
2. Разрешите установку APK, если Android попросит.
3. Установите поверх имеющейся версии, **не удаляя игру**.
4. Запустите игру и продолжайте играть.

Package ID и ключ подписи сохранены. Настройки и сохранённый сюжет используют прежнее хранилище. Все игровые данные внутри APK; для одиночной игры Интернет и другие приложения не нужны. Требуется Android 10 или новее.

## Что изменилось

- Красная рукоятка аркадного стика.
- Кнопки A, B, C — соответственно красная, жёлтая, зелёная. Буквы на экранных кнопках убраны.
- Start вверху справа — белая кнопка со значком паузы, без надписи.
- Короткий системный виброотклик при новом касании кнопки атаки или Start. На стике, при удержании и отпускании вибрация не запрашивается.

Оттенки взяты из предоставленной фотографии. Яркость зависит от прежней настройки прозрачности и изображения под кнопкой. Положение и размер элементов сохранены. У дополнительных бойцов набор кнопок прежний.

Виброотклик зависит от вибромотора и системной настройки тактильной отдачи Android. Приложение уважает эту настройку; дополнительных разрешений не требуется.

## Короткая проверка на телефоне

1. Начните обычный VS за Люси: справа должны быть красная, жёлтая и зелёная кнопки без букв, слева — красный стик.
2. Несколько раз нажмите каждую кнопку, затем удержите: ожидается короткий отклик при новом нажатии, без повторов во время удержания.
3. Ведите стик по кругу и удерживайте направление: вибрации от стика быть не должно. Вторым пальцем нажмите кнопку: отклик относится к этому нажатию.
4. Нажмите белую кнопку сверху справа: открывается прежняя пауза с коротким откликом.

Если отклика нет, проверьте системную настройку тактильной отдачи. Для обратной связи достаточно модели телефона, версии Android и результата этих четырёх действий.

Сборки и программные проверки пройдены. Установка этой версии и фактическая вибрация на физическом Android в среде разработки не проверялись. Результаты и границы проверки — `TEST_RESULTS_007C.md`. Известные ограничения остального порта сохранены в `KNOWN_ISSUES.md`.
