# Проверка TEST 007 на Android

Установите `elfen-fighting-007-select.apk` поверх TEST 006. Удалять приложение не нужно. Проверки выполняются без Интернета, компьютера и сервера.

## Сетка и портреты

Откройте «Обычный VS». Нажмите по очереди на десять маленьких портретов. Должны меняться крупный персонаж и его анимация, курсор должен переходить к выбранной ячейке. Проведите пальцем между соседними ячейками. Растяжения картинки быть не должно; чёрные поля допустимы.

Люси — слева в четвёртом ряду, Нана — справа в пятом. Слева сверху — Ню.

## Пара бойцов и возврат

Выберите Люси и удерживайте «Выбрать бойца» две секунды. Должен открыться выбор противника, но бой не должен начаться сам. Отпустите кнопку.

Нажмите «Назад»: снова выбирается ваш боец. Подтвердите Люси, выберите Нану и нажмите «Начать бой». Примерно через 1,7 секунды должен начаться матч: Люси слева, Нана справа. Проверьте движение и атаку.

Menu → «Новый матч»: выберите Нану с обеих сторон. Должен загрузиться зеркальный бой. Если подключён геймпад, направления перемещают курсор, A–F подтверждают; удержание направления повторяется.

## Сюжет и Home

Menu → «Сюжет»: выберите Люси. Должна открыться её сцена, после A–F — первый бой. В бою откройте Menu → «Другой персонаж», затем «Назад» и «Продолжить»: прежний сюжет должен сохраниться.

Снова откройте выбор, нажмите Home и вернитесь. Экран должен продолжить работу без случайного подтверждения и зависшего звука. После выбора нового бойца кнопки боя должны работать как в TEST 006.

## Что сообщить

1. Все ли десять ячеек выбираются под пальцем?
2. Есть ли пропавшие портреты, анимации или обрезанные кнопки?
3. Работают ли «Назад», удержание подтверждения и выбор противника?
4. Начинаются ли VS и сюжет за выбранного бойца?
5. Есть ли сбой после Home, пропавший звук или crash? Укажите точное действие.

При ошибке сохраните отчёт через Menu → «Поделиться отчётом». На остановленном экране выбора нажатие вне «Назад» открывает отправку отчёта. Повторять все базовые боевые проверки TEST 006 не требуется.
