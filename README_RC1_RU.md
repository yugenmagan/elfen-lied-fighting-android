# Elfen Lied Fighting — Android RC1

Установи **elfen-rc1.apk** поверх предыдущей версии и запусти игру. Если Android спросит, разреши установку из приложения, которым открываешь APK. Windows, дополнительные приложения, копирование ресурсов и Интернет для одиночной игры не нужны.

При первом запуске этой версии галочкой отмечен **English**. Выбери English, 日本語 или Русский. Следующий выбор запоминается. Название приложения — **Elfen Lied Fighting**; отметок TEST в игровом интерфейсе нет.

После выбора языка появится оригинальный титульный экран. **New Game / Новая игра** открывает выбор режима: Story / Сюжет либо Versus / Обычный VS. Затем выбери персонажа. В VS выбирается также противник.

**Continue / Продолжить** доступно, если в этом же запущенном приложении осталась приостановленная игра. При Home, блокировке экрана и переходе в другое приложение бой и звук останавливаются. После возвращения нажми «Продолжить» на главном экране. Пока ты этого не сделал, бой не идёт.

После закрытия приложения, удаления его из списка недавних или выгрузки процесса Android текущая игра прекращается. При новом запуске «Продолжить» будет неактивно. Старое автосохранение TEST008 больше не загружается; всплывающего окна «Сохранённый сюжет» нет. Настройки языка и управления сохраняются.

Слева — красный аркадный стик. Справа — красная, жёлтая и зелёная кнопки. Белая кнопка сверху открывает паузу. В паузе доступны продолжение, список приёмов персонажа, настройки и возврат на главный экран. Из списка приёмов и настроек «Назад» возвращает в паузу; «Продолжить» закрывает её. Системная кнопка Back непосредственно в паузе также продолжает игру.

В настройках можно изменить прозрачность, размер, мёртвую зону, зеркальное расположение и назначение кнопок геймпада. Для перестановки элементов открой настройки во время игры; закончив перемещение, нажми белую кнопку паузы.

Оригинальный логотип на стартовом экране сохранён: `デモ 2.demo`, pack `0074`, image `11`. Это экран, на который прямо указывает исходная таблица KGT; картинка взята из самой игры. Названия новых пунктов меняются вместе с языком. Иконка Люси сохранена из предыдущей версии: оригинальный портрет `0170/0135.png`.

RC1 — кандидат для проверки финального интерфейса. Сборка, подпись и автоматические проверки пройдены. В текущей среде нет Android Emulator и подключённого телефона; физическая проверка этой версии ещё не проведена. Онлайн-клиент сохранён, но общедоступный сервер не размещён и новый интернет-бой этой сборкой не проверен. Эта работа ничего не публикует.

## Короткая проверка на телефоне

1. Запусти игру: выбран English, после выбора языка видна оригинальная заставка. В бою нет TEST, кода кнопок и служебной строки.
2. Начни бой, открой паузу → Moves → Back → Continue. Повтори через Settings. Должен продолжиться тот же бой; меню не должно появляться снова.
3. Во время боя нажми Home, подожди и вернись. Должна быть заставка с активной Continue. До её нажатия бой и звук стоят. Нажми Continue: здоровье и положение бойцов сохраняются. Повтори с блокировкой экрана.
4. Закрой приложение через список недавних или «Остановить» в настройках Android, затем запусти заново. Продолжить старый бой нельзя.

Сообщи, какой из этих пунктов не совпал с ожидаемым, если такое случится.
