# Проверка TEST 008 на Android

Установите `elfen-008.apk` поверх предыдущей сборки, не удаляя игру. Это обновление двух функций: языки и результат финального боя. Боевые параметры и управление прежние.

1. Запустите игру. В окне должны быть **日本語** с флагом Японии, **English** с флагом США и **Русский** с флагом России. Выберите «Русский».
2. Начните новый сюжет за Люси. Меню и экран выбора должны быть на русском. В начале сцены должна появиться реплика «Я вас всех защищу.», затем «Ведь теперь и у меня есть что защищать...», затем заголовок «Сломленный ангел». Красная A продолжает сцену.
3. В бою откройте белую Start → Меню игры → Настроить управление → Язык. Выберите English. Настройки и список приёмов должны стать английскими; после выхода из паузы бой продолжается с прежнего состояния.
4. Начните новый сюжет с English: вступление Люси — “I'll protect you all.”, заголовок — “Broken Angel”. Проверьте, что буквы не обрезаются рамками. Для 日本語 должны вернуться исходные японские надписи.
5. Сверните и откройте игру. При новом запуске выбранный язык отмечен галочкой; сохранённый сюжет можно продолжить. При поражении финальному боссу должен появиться Continue, без концовки. «Продолжить» — повторный матч с тем же боссом. Только победа в матче открывает концовку и титры.

Для первого ответа достаточно пунктов 1–4. Финального босса можно проверить при следующем прохождении; специально удалять сохранение не требуется.

Сообщите выбранный язык, персонажа и место ошибки. Если текст обрезан — приложите кадр. Если после проигрыша всё ещё открылась концовка — укажите счёт раундов и загружали ли старое сохранение. При crash укажите действие перед ним; отчёт доступен через меню игры.

Автоматически проверены: 581 сценарий исхода финального боя для десяти маршрутов; настоящее поражение Люси 0:2 и победа маленькой Люси с неизменёнными HP/AI/уроном, затем концовка и титры; три языка, все 27 DEMO, размеры переводов и исходные ресурсы. Это не заменяет проверку APK на телефоне.
