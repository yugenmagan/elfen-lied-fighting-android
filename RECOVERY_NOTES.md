## Сборка и новый checkpoint

Проверенная точная сборка: `python3 tools/build_android.py`; проверка эквивалентности: `python3 tools/check_apk.py`.

Gradle и проверка нового ZIP фиксируются окончательным протоколом ниже. Новый ZIP создаётся инструментом `tools/package_recovery.py`: проверяет CRC всех записей, распаковывает в отдельную папку, собирает только из распакованных исходников и проверяет совпадение APK с эталоном. В архив не включаются готовый APK, кэши компилятора, SDK и Gradle dependencies. Поэтому успешная проверка не может использовать оставшиеся class/dex файлы предыдущей сборки.

### Gradle

`./gradlew --no-daemon assembleRelease` успешно завершён: **BUILD SUCCESSFUL, 43 задачи выполнены**. В окружении Java не подхватывала штатный HTTP/HTTPS proxy автоматически. Первый запуск завершился Network is unreachable; после передачи уже заданных средой proxy-настроек загрузились официальный Gradle и AGP. Проверки TLS/checksum не отключались. Код приложения не менялся. Логи обеих попыток сохранены.

Готовый Gradle APK: `app/build/outputs/apk/release/app-release.apk`. Для пользовательской recovered-сборки выбран standalone APK, поскольку именно он доказанно совпадает с эталоном целиком.

### Целостность доставляемого ZIP

Проверка опубликованного checkpoint состоит из CRC всех записей, распаковки в отдельное дерево и сборки APK из него. Точный SHA-256 ZIP и результат этой проверки вынесены в `RECOVERY_CHECKPOINT_VERIFICATION.json` рядом с архивом: файл проверки нельзя поместить внутрь проверяемого ZIP без изменения его собственного хеша. Непроверенный архив не выдаётся как завершённый checkpoint.
