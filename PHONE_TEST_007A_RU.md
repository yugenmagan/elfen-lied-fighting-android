# Проверка TEST 007a на Android

Установите `elfen-fighting-007a-stick.apk` поверх TEST 007. Удалять игру не нужно. Компьютер и Интернет для игры не требуются.

## Стик — главная проверка

1. Откройте «Обычный VS», выберите Нану и Люси. Menu → «Уровень AI» → «Манекен (0)»: начнётся новый матч с неподвижным противником.
2. Ведите стик влево/вправо; затем вниз, вверх и по диагоналям. Рукоятка должна следовать пальцу, персонаж — ходить, приседать и прыгать. Отпустите палец: направление должно выключиться, рукоятка вернуться в центр.
3. Удерживайте направление и одновременно нажмите A и B двумя другими пальцами. Ввод не должен прерываться при отпускании только одной из кнопок. Результат самой комбинации зависит от оригинальных команд персонажа.
4. Проведите ↓ ↘ → и нажмите A: должна распознаваться «ロケット弱» у Наны. При развороте в другую сторону зеркально измените движение.
5. Уведите палец за край круга, продолжая держать направление. Оно должно сохраняться. Откройте Menu при удержании, затем продолжите: зажатого направления быть не должно.
6. Проверьте Home → возврат и блокировку → разблокировку. Нужны свежие касания; персонаж не должен сам продолжать идти.
7. Если необходимо, настройте размер и мёртвую зону. При маленькой мёртвой зоне направление включается от меньшего движения пальца. Проверьте перенос и зеркальное расположение.

## Банка — дополнительная визуальная проверка

Нана слева, Люси справа; AI0. Выполните ↓ ↙ ← + B и подождите, пока банка доедет до стоящей Люси. Смотрите на числовое HP: первое прямое попадание должно изменить **400 → 395**. Скольжение средней банки соответствует оригинальному скрипту. С дальней позиции ожидание может занять несколько секунд.

Для A подойдите ближе; для C банка падает дальше впереди. Когда персонаж меняет сторону, направление команды зеркально меняется. Промах по дистанции или блок — не подтверждение ошибки урона. Результат попадания при AI0 легче отличить от блока.

## Что сообщить

- Удобно ли удерживать стик и делать круговые движения?
- Получаются ли диагонали и направление + две кнопки? Что именно пропускается, если есть проблема?
- Есть ли застрявший ввод после Menu/Home/блокировки?
- Изменилось ли HP Люси с 400 на 395 при первом прямом попадании банки B?
- Модель телефона и действие перед crash, если он был. Menu → «Поделиться отчётом» сохраняет диагностику; приложение само ничего не отправляет.
