# v1.0.0-rc1, build 14 — текущие ограничения

- Новое расположение кнопок проверяется геометрически и отрисовкой; результаты Android Emulator отдельно указаны в TEST_RESULTS_RC1A.md. Удобство, latency, вибрация и звук новой сборки на физическом телефоне ещё не подтверждены.
- Онлайн-сервер не размещён; реальный интернет-бой этой версией не проверен. Публикация исходников/APK разрешена пользователем; размещение сервера требует отдельного выбора.
- При выгрузке приложения текущая игра теряется намеренно, по новому требованию. Continue работает только для оставшейся в памяти сессии.
- Оригинальный логотип на титульном экране остаётся японским во всех языках; пункты меню переводятся.
- Сохраняются ограничения переноса оригинальной логики, перечисленные ниже в исторических заметках.

# Ограничения TEST 008

TEST008 собран и проверен автоматически, но новый APK здесь не запускался на Android: adb, эмулятор и KVM отсутствуют. Native-экран языка, системные шрифты, установка поверх007d и переключение языка при сворачивании требуют проверки телефона по README_TEST_008_RU.md.

- Локализован доступный пользовательский текст сцен и UI, включая титры и список приёмов. Озвучка осталась японской. Декоративные вывески на фоновых рисунках, мелкий псевдотекст титульной картинки и branding сохранены. Технические исключения сторонних API могут оставаться английскими.
- Для нескольких подписей поверх рисунка применены аккуратные текстовые панели. Это отличается от исходного рукописного оформления; японский режим использует оригинальную картинку. В EN/RU используются системные Android-шрифты; метрики на устройстве могут отличаться от desktop-preview.
- Сюжетный итог финального матча изменён намеренно: исходный флаг разрешал переход после поражения; новая policy требует победы. Проверены все10 веток через исходные события и fixtures, плюс реальное поражение Люси0:2 и победа маленькой Люси через обычные направления/кнопки с последующей концовкой и титрами. Полное естественное прохождение с победой над боссом на новых правилах в TEST008 не заявляется. Прежние полные маршруты нельзя автоматически засчитывать как новый выигрыш.
- Онлайн-клиент/rollback/комнаты унаследованы без изменений; общий сервер не размещён, интернет-бой между телефонами не подтверждён. Выбор размещения сервера остаётся отдельным действием пользователя.

## Сохраняющиеся ограничения runtime

- На узких экранах арена немного уменьшается для боковых полей управления; 4:3 сохранено. Пользовательские позиции ограничены этими полями.

- У PLAYER0142/0144 (Крафт) и0154 (プレーヤー1) исходный навык боевого портрета пустой. Для них отсутствующая в исходнике картинка не придумана. Все десять бойцов основной сетки имеют портреты. Альтернативные палитры ещё не реализованы.
- Полное покадровое сравнение всей Windows-игры не выполнено. Отдельные combat/CPU/commands/match/story/HUD процедуры сопоставлены с исполнением x86. Порт сохраняет60 ticks/сек; полный исходный task scheduler и все графические эффекты не восстановлены.
- Перенос скорости у стены, камера, все solid collisions, тени и afterimages не полностью восстановлены. Visual opcode14 создаёт событие, но эффект не рисуется. Alpha/add могут округляться иначе, чем Windows framebuffer.
- Служебные переменные таймера/раунда произвольных character scripts ещё не связаны полностью с match controller. У Ню есть условные ссылки158/160 вне таблицы153 skills; они не заменены заглушками. У Анны skill88 содержит исходные нулевые guard-junctions: reaction-error2/пропуск урона сохранены и диагностируются.
- Пустая result-анимация удерживает последнюю позу до следующего раунда; это исправление зацикливания порта, не подтверждённое полное поведение renderer Windows. Зеркальный AI Нана–Нана может остановиться вне дистанции атаки. AI не менялся ради обхода таких случаев.
- UI меню/Continue адаптирован к Android. Оригинальные selection assets и боевой HUD используются, но полного пиксельного сравнения всей игры нет.
- Audio focus, тембры MIDI, физические геймпады, latency, производительность и вибрация зависят от устройства. Touch сохраняет multi-pointer ввод; системный haptic вызывается только при нажатии кнопок. Analog LT/RT закреплены на E/F; элементы перемещаются двумя группами.
- Дисковое продолжение из старых TEST-сборок в RC1 отменено по требованию пользователя. Ручной snapshot существует в текущем процессе; UI импорта replay отсутствует. Старые replay сохраняют старую identity/policy; их нельзя считать мигрированными пользовательскими сохранениями.

Подробная история предыдущих ограничений и сетевых тестов — research/historical/KNOWN_ISSUES_007D.md. Текущий APK не называется завершённым полным портом.
