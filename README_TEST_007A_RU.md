# Elfen Lied Fighting — TEST 007a

Исправление управления в ветке TEST 007. Это промежуточная версия порта, не TEST 008.

## Установка

1. Скачайте `elfen-fighting-007a-stick.apk`.
2. Разрешите установку APK, если Android попросит.
3. Установите поверх TEST 007, не удаляя приложение: ключ подписи прежний.
4. Запустите игру и выберите «Обычный VS» или «Сюжет».

Android 10+, arm64/x86_64; игровые данные уже внутри APK. Одиночная игра работает без Интернета и дополнительных приложений. Прежние настройки и сохранения TEST 005–007 совместимы; боевая система и данные не изменены.

## Аркадный стик

Вместо стрелок слева — круглая база и подвижная рукоятка. Коснитесь стика и ведите палец в нужную сторону. Диагонали и непрерывные круговые движения работают без отрыва пальца. Выход пальца за окружность не отпускает направление. Отпускание возвращает рукоятку в центр.

Справа прежние шесть кнопок A–F. Можно держать стик одним пальцем и нажимать две кнопки другими. Стик управляет восемью исходными направлениями: отклонение не меняет скорость персонажа.

Menu → «Настроить управление»: прозрачность, размер, мёртвая зона, зеркальное расположение и скрытие управления при подключённом геймпаде. Menu → «Передвинуть элементы»: переместите стик и кнопки, затем завершите настройку тем же пунктом меню. Положения сохраняются.

## Что выяснилось про банку Наны

Проверены исходные скрипты и отдельные процедуры оригинального EXE. У банки три варианта. Здесь направления указаны для Наны, стоящей слева и смотрящей вправо:

| Ввод | Исходное поведение |
|---|---|
| ↓ ↙ ← + A | Банка появляется рядом впереди и стоит на месте. |
| ↓ ↙ ← + B | Банка медленно скользит вперёд. Это прописано в оригинале. |
| ↓ ↙ ← + C | Банка падает сверху дальше впереди; прямая атака активируется после приземления. |

При обычном прямом попадании в Люси банка снимает **5 HP из 400**. Это небольшое изменение полосы. Без повторного включения атаки тот же объект не наносит второй прямой удар. При блоке прямого попадания урон равен нулю, но запускается другая фаза с четырьмя атакующими объектами; они сами могут наносить урон. Поэтому «заблокировал банку» не означает безопасность от всего приёма.

Урон, скорость, хитбоксы и команды сохранены. Подтверждённого расхождения именно в проверенных сценариях банки не обнаружено; полного совпадения всего Windows runtime это не доказывает.
