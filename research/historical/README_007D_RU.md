# Elfen Lied Fighting — TEST 007d

Обновление оригинального боевого интерфейса поверх 007c: рамки здоровья с портретами, голубые полосы HP, таймер с исходными цифрами и нижние шкалы спецприёмов с числом зарядов. Используются ресурсы самой игры. Красный стик, цветные кнопки без букв и виброотклик кнопок сохранены. Подробности — `README_TEST_007D_RU.md`. Это ещё не TEST 008 и не финальная версия полного порта.

## Установка

1. Скачайте `elfen-007d.apk`.
2. Разрешите установку APK, если Android попросит.
3. Установите поверх имеющейся версии, **не удаляя приложение**: подпись и package ID прежние.
4. Запустите игру, выберите «Сюжет» или «Обычный VS» и персонажа.

Android 10+, включая arm64 и x86_64. Все игровые данные уже внутри APK. Для одиночной игры не нужны Интернет, Windows и другие приложения. Настройки и сохранения 007c используют прежнее хранилище. Правила боя этой минорной версией не меняются.

## Управление

Слева — аркадный стик с красной рукояткой. Ведите палец по кругу, не отрывая: доступны восемь направлений и диагонали. Отпускание возвращает стик в центр.

Справа показаны только используемые персонажем кнопки, без букв. Цвета основных кнопок: A — красная, B — жёлтая, C — зелёная. Их назначения:

| Боец | Кнопки |
|---|---|
| Десять персонажей исходного экрана выбора | A, B, C |
| Дополнительный Крафт | A, B, C, D; D — исходная команда キャンセラー |
| Второй дополнительный боец с исходным именем プレーヤー 1 | A, B |

Неиспользуемые D/E/F убраны. Дублирующих атак и придуманных функций нет. Можно удерживать стик и нажимать несколько кнопок другими пальцами. Сохранено объединение одновременных нажатий в пределах одного игрового кадра из 007b.

«Пауза → Меню игры → Настроить управление»: размер, прозрачность, мёртвая зона, зеркальное расположение, скрытие touch-кнопок с геймпадом. «Передвинуть элементы» перемещает стик и блок атак. Чтобы закончить перемещение, нажмите «Пауза», затем «Продолжить бой».

## Пауза и приёмы

Вверху справа — белая кнопка Start со значком **Ⅱ**, без надписи. Она останавливает бой и звук. В меню паузы доступны продолжение, приёмы текущего бойца и меню игры. Просмотр списка или настроек не возобновляет бой автоматически. Кнопка Back в главном окне паузы также возвращает в игру.

В списке сохранены названия из японских данных. Направления показаны лицом вправо; с другой стороны они зеркальные. Запятая означает следующий ввод, `+` — одновременно, `•` — отпустить стик. Удержания указаны в кадрах: 60 кадров = 1 секунда. Показаны доступные исходные команды, включая обычные и специальные; применение может требовать соответствующего состояния или энергии. Названия «суперприём» и значения стоимости не приписываются по догадке.

## Раунды

Новые офлайн-матчи VS и сюжетные бои идут **до двух побед**. При 2:0 матч окончен; при 1:1 нужен решающий раунд. Ничья и double KO не дают победу ни одной стороне, поэтому при ничьих раундов может быть больше трёх.

Следующая сцена/противник или Continue появляются после исхода матча, а не после первого KO. Между раундами восстанавливаются HP, позиции и таймер, удаляются объекты прежнего раунда. Запас энергии переносится по прежним правилам движка. Выигранные раунды теперь отмечены исходными значками рядом с портретами. Числовая служебная надпись счёта и номера раунда убрана из игрового поля.

Скорость, урон, хитбоксы, персонажные скрипты, AI и аркадный стик не изменены. Таймер сюжета берётся из оригинальных событий. Онлайн-правила этой итерацией не переделывались.

## Банка Наны

Исследование 007a сохранено: слабая банка стоит, средняя скользит, сильная падает сверху. Прямое попадание снимает 5 HP у Люси; после контакта могут включаться другие фазы. Это поведение исходных скриптов. Подробности — `docs/NANA_CAN_007A.md`.
