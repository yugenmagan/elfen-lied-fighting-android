# Компоненты и материалы

Сборка предназначена для личного переноса предоставленных пользователем файлов. Оригинальная Elfen Lied Fighting, её EXE, графика, музыка, реплики и прочие материалы не объявляются открытыми или свободными для публичного распространения. Исходный Fighting.zip не изменяется, APK/ресурсы публично не размещались.

## В APK

Собственный Java-код проекта и производные представления предоставленных пользователем игровых данных. Используются встроенные Android API Canvas, MotionEvent, SoundPool, MediaPlayer; копия Windows/Wine/Winlator/Box64 не включена. В APK нет JNI .so-библиотек и стороннего коммерческого редактора.

## В исходном проекте

- fm2ndparser, commit7266d65b9ca486a619b6b10836ee0cfed734fefb, автор Xem85, MIT. Исходники этого внешнего ориентира формата не включены в компактный recovered checkpoint; собственный parser сохранён в tools/inspect_containers.py. Использовался как ориентир формата, не как Windows runtime.
- Официальные Gradle8.9 wrapper scripts/JAR. Лицензия и notices: gradle/GRADLE_LICENSE. Получены из https://github.com/gradle/gradle/tree/v8.9.0; SHA-256 wrapper проверен по https://services.gradle.org/distributions/gradle-8.9-wrapper.jar.sha256. Gradle distribution в проект не включён.

## Инструменты, загружаемые отдельно

- Android SDK Build Tools/Platform: официальные dl.google.com/android/repository, лицензионные условия входят в соответствующие SDK packages. SDK-бинарники не включены в проект или APK.
- JDK17: используется установленный в среде; не включён.
- Pillow12.3.0: HPND/Pillow license, используется только конвертером; не включён в APK.
- Unicorn2.1.4: GPL-2.0, используется только изолированными исследовательскими probes, не включён в APK/архив проекта.
- pefile2024.8.26: MIT, только исследование; не включён.
- Capstone5.0.6: BSD license, только исследование; не включён.

Ссылки служат указателями на происхождение; наличие инструментов не меняет права на игровые материалы. Русская локализация ресурсов в этой итерации не выполнена.
